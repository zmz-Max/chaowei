## 写作规范（按手册要求）

1. 全部使用 markdown（`.md`）格式。
2. 按机器人设计进度的时间顺序组织内容。
3. 以单个机器人功能为一个板块：**具体功能（H2 标题）+ 功能描述与开发历程（正文）**。
4. 技术部分不仅写“做了什么”，更要写“为什么这样做”：技术选型对比、遇到的难点与解决方案、迭代优化过程。
5. 使用到的开源项目在文档末尾完整说明，并遵守其开源协议。

### 基础功能指标自查

- [ ] 外形展示：能量单元 + 完整机体绕车一周
- [ ] 电机运动（单一）：至少 1 个电机转动
- [ ] 电机运动（全部）：不少于 4 个电机转动
- [ ] 舵机运动（单一）：至少 1 个舵机转动
- [ ] 舵机运动（多项）：同台机器人 ≥3 个舵机转动，且非初始状态下可保持相对静止
- [ ] 底盘运动（单一）：PS2 控制至少一个底盘水平运动
- [ ] 底盘运动（全部）：PS2 控制全部车体水平运动
- [ ] 尺寸规范：初始长宽 ≤290×195mm、高 ≤210mm，重量 ≤2.0kg
- [ ] 方块携带（单一）：自主把地面静止的 30×30×30mm 方块变为携带状态
- [ ] 方块携带（多项）：保持携带状态下再携带第二块
- [ ] 结构稳定性：180mm 自由落体无零件掉出
- [ ] 规划 / 现有采购单：核心部件选型与整机成本预算
